# Globe Stacks: project notes

Keep this file in the project. Upload it with the zip at the start of every new chat.
Last updated: 2026-11-18.

## Decisions
- Name: Globe Stacks. Language: English. Free hosting: GitHub + Cloudflare Pages (globe-stacks.pages.dev).
- Audience: Tanzanian students first. Widen to other African countries later.
- Scholarships are international (study abroad), not Tanzania-based awards.
- **Level: undergraduate (bachelor's) only. No master's, PhD or high-school (e.g. UWC) scholarships.**
- Funding levels: Fully funded and Partly funded only. No student-loan content.
- Goal: all-in-one and well detailed, so students never need to "check with someone else". Every entry has an official link and a verified date.
- Contact: globe.stacks@gmail.com, WhatsApp +255 638 789 255.
- Logo: blue globe with stacked layers. App icon: full navy square, no transparent corners.

## How we work (to stay within the free plan)
- One task per message. No parallel agents, no whole-site regeneration, no full zips.
- Send only the changed files each time.
- New chat per stage. Start by uploading the zip and this file.
- Scholarships: 1-2 per message, one small file each in content/scholarships/.
- Before writing a new entry, check the official page for: Tanzania eligibility, level, what is covered, deadline and year. If the official page does not say, write "not confirmed" in the entry. Do not copy dates from blog sites.
